# OFL Cyrillic Extension · 1.0.0

Переносимый скилл для **Claude Code и Codex** и отдельная русская инструкция.
Сделан для Yerbolat Rakhatuly (DEW). Обучает агента исследовать новую гарнитуру,
строить кириллицу по её закономерностям и проверять результат. Не содержит готовых
контуров Very Peri, формул с фиксированными толщинами и обещания безошибочной кнопки.

## Как пользоваться

После установки передай шрифт и, если есть, его OFL/ссылку на upstream:

> Используй ofl-cyrillic-extension. Добавь кириллицу к приложенному латинскому
> шрифту, сохрани его характер и родную латиницу. Выполни работу и сам проверь
> результат по скиллу; сохрани исходники, шрифты и отчёт.

Для Codex можно явно вызвать `$ofl-cyrillic-extension`. При явном вызове и одном
переданном файле по умолчанию выбран RU + KZ в приложенных начертаниях. Скажи иной
набор, если он нужен. Автовыбор по description зависит от клиента/включённых навыков;
простая загрузка файла не гарантирует запуска скилла во всех интерфейсах.
Агенту нужны чтение/запись файлов, Python и возможность смотреть векторные/растровые
образцы. Одни текстовые ответы не заменяют эту среду. Шрифты не генерируются
одним из поставляемых скриптов: агент проектирует их по методике и создаёт
сборщик, подходящий их формату, источникам и вариативности.

## Установка в другой проект

Скачай ZIP, распакуй папку `ofl-cyrillic-extension`, затем:

```sh
python /absolute/ofl-cyrillic-extension/scripts/install_skill.py --project /absolute/my-font-project --client both
```

Будут созданы **`.agents/skills/ofl-cyrillic-extension`** для Codex и
**`.claude/skills/ofl-cyrillic-extension`** для Claude Code. Для одного клиента
выбери `--client codex` или `--client claude`. Совпадающая копия не перезаписывается.
Отличающаяся копия блокирует установку; `--replace` сохраняет её в резервном каталоге.
Глобальные каталоги пользователя и настройки клиента установщик не меняет.
Открой проект/новый сеанс, чтобы клиент перечитал доступные навыки.

В исходном репозитории те же project-level пути указывают на один канонический
каталог `skills/ofl-cyrillic-extension`; дублировать редакции не требуется.
В Claude-интерфейсе с поддержкой загрузки пользовательских навыков можно пробовать
ZIP со SKILL.md в единственном корневом каталоге. Для инструментов всё равно нужна
Python-среда; совместимость конкретного веб/desktop-интерфейса отдельно не проверена.

`assets/owner-profile.json` содержит имя владельца **этого** комплекта. При передаче
другому автору замените профиль, а upstream-авторство шрифта сохраните.

## Инструменты

Python 3.12; проверенные версии зависимостей закреплены. Выполняй команды из
каталога скилла, входные/выходные пути проекта задавай явно:

```sh
python -m pip install -r scripts/requirements.txt
python scripts/font_probe.py /absolute/input.ttf --out /absolute/project/reports/intake --license /absolute/OFL.txt
python scripts/audit_outlines.py /absolute/output.ttf --out /absolute/project/reports/contours.json
python scripts/compare_native.py /absolute/input.ttf /absolute/output.ttf --out /absolute/project/reports/native.json
```

Probe сохраняет неизменённый вход, инвентарь, базовые measurements и
`native-controls.svg`. Данные лицензии остаются `unverified`, пока агент не проверит
происхождение и условия. Для TTC нужен явный `--font-number`. `--location wght=400`
задаёт только измерение экземпляра VF, не изготовление кириллического VF.
Профили сечений при нестандартной location не вычисляются вместо смешивания осей.

Audit обходит весь glyph order и сообщает ошибки отдельно от кандидатов.
Обычный exit 0 означает завершённое чтение, **не оптическую приёмку**.
`--require-reviewed` возвращает код 3, пока есть незакрытые кандидаты или целые
формы без просмотра. `--rules calibrated.json` задаёт положительные значения
известных порогов; они и исходники детектора включены в hash. Данные ledger:

```json
{
  "forms": {
    "REVIEW_KEY_FROM_REPORT": {
      "status": "reviewed", "font_sha256": "FROM_REPORT",
      "geometry_sha256": "FROM_REPORT", "detector_sha256": "FROM_REPORT",
      "reason": "Конкретное решение после просмотра целого глифа",
      "proofs": ["proofs/that-glyph.svg"]
    }
  },
  "cases": {}
}
```

Case-решения используют ID из отчёта, те же три hash/причину/proofs и статус
`intentional` или `resolved`. Решение привязано к конкретным файлам и детектору.
Не генерируй ledger с массовыми одобрениями без просмотра. Разбор пересечений
по flattening требует подтверждения на настоящих Bézier.

Native comparison проверяет все входные глифы/метрики, hints и cmap; HarfBuzz —
отдельные наследуемые Latin-символы и ограниченную выборку контекстов/функций.
Это **не полная матрица кернинга** и не проверка всей языковой локализации.
Форматы контуров должны совпадать; статический TTF сопоставляй с TTF, CFF — с CFF.
Осознанное изменение существующей кириллицы требует отдельной декларации/проверки,
этот строгий скрипт иначе правильно сообщит о несовпадении.

Для точного сокращения точек подготовь JSON-массив имён **своих новых глифов**,
например `["uni0436", "uni0437"]`. По умолчанию только анализ:

```sh
python scripts/reduce_nodes.py /absolute/new.ttf --glyph-list /absolute/new-glyphs.json --report /absolute/nodes.json
python scripts/reduce_nodes.py /absolute/new.ttf --glyph-list /absolute/new-glyphs.json --report /absolute/nodes-applied.json --output /absolute/new-reduced.ttf
```

Apply требует нового выходного пути; исходник никогда не заменяется. Проверяется
весь сериализованный набор. Hinted/flagged глифы и опасные зависимости защищаются;
индексные GPOS/GDEF/VF/VTT-данные могут блокировать применение целиком. Это
консервативный инструмент для static glyf, не оптимизатор CFF и не редактор VF.
Не подавай в allowlist родную латиницу только потому, что там найдена лишняя точка.

## Проверка самого комплекта

```sh
python -m unittest discover -s tests -v
```

Тесты включают известные геометрические дефекты/намеренные углы, near-miss точного
упрощения, другой UPM, hints и индексные зависимости, отрицательный native-regression,
покрытие/ledger gate, снимок входа и повторную безопасную установку.
В репозитории дополнительно проверены реальные входы и запуск распакованного ZIP
вне Very Peri. Результаты: `docs/qa/skill-validation-1.0.0.json`.

Готовые команды для полного OTS/FontBakery/браузера/PDF агент добавляет в проект
по фактическому toolchain. Эти проверки не исполняются молча описанием скилла.
У комплекта нет доступа к публикации или токенам; внешние действия требуют
соответствующей задачи пользователя. Лицензия/происхождение — `LICENSE.txt`, `NOTICE.md`.
