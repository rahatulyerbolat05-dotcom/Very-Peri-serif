# Происхождение комплекта

Методика подготовлена для **Yerbolat Rakhatuly (DEW)** по опыту разработки
Very Peri Serif с помощью Claude и Codex. Это инструменты разработки, не отдельные
правообладатели. Дата редакции: 25.10.2026; версия скилла: 1.0.0.

`outline_geometry.py` и основа `exact_nodes.py` перенесены из инструментов
Very Peri Serif 1.113, commit `d1651d5507b06109994354aab1a6d62689cd8ff3`.
Остальные инструкции, обвязки, шаблоны и переносимые тесты созданы для этого комплекта.
Сохранена SIL OFL 1.1 и шапка уведомлений проекта в `LICENSE.txt`.
Это сопроводительная документация и инструменты проекта, не смена его лицензии.
Готовых шрифтов, донорских контуров и измерений для подстановки в новый шрифт здесь нет.
Лицензию каждого нового входного шрифта проверяй отдельно: лицензия комплекта её не заменяет.

Названия Instrument/Cormorant указывают происхождение исходного проекта,
не одобрение скилла этими авторами. Ограничения и неудачные решения сохранены
в `references/lessons.ru.md`; качество прежнего проекта не объявляется эталоном
без дефектов. Для изменённых инструментов нужно заново проводить проверку.
