# Й Ф Я — заглавные предложения

Запрос «й,ф,я» интерпретирован как продолжение работы с заглавными;
пользователю отправлено уточнение, ответа на момент построения не было.
По одному варианту на рассмотрение; строчные не заменены.

Й: прежняя И, точная brevecomb из Regular, перенос(+69,+210).
Высота кратки789..940, центр273; посадка соответствует родной Ubreve.
В TTF — компоненты uni0418 и uni0306; ccmp обеспечивает И+U+0306=Й.
Ф: новый овал с боковой толщиной79 и верхом/низом27, центр325/360,
центральная стойка71 с точными засечками I, перенос(+200.5,0).
Овал занимает y90..630, стойка0..720. Объединение контуров pathops,
три контура, два раздельных просвета; без глобального сглаживания.
Я: зеркальная чаша/стойка P как скелет, новая тонкая восходящая нога,
нижняя левая засечка из A с двумя локально исправленными ручками
для касательного перехода. Нога не наследует толстую диагональ R.
Пересечения объединены pathops; advance519, боковые интервалы предварительные.

GLIF/design.json — кубические исходники, TrueType-приближение0.5 UPM.
Проверены топология исходных/экспортных контуров выборкой200 точек/кубик,
HarfBuzz слова, ударения, каноническая запись Й, сохранение старых глифов
и метрик, латинских пар и контекстных замен. Исходная И не изменена.
Два файла сборок сохраняют открытые й01/02: это не варианты заглавных.
Новые кернинговые пары и хинтинг не выполнены; FontBakery/Hyperglot не запускались.
