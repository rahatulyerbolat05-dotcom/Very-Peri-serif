# Измерения и векторные справочные листы

[НАБЛЮДЕНИЕ] Сохранён исторический анализ официальных Regular и Italic источников Instrument Serif (`65c0ef225f386a3c7e87570a4aa9cc0262c2fd81`). SVG содержат контуры доноров, узлы и сравнительные схемы; оригинальные отдельные бинарные шрифты сюда не включены.

[ИЗМЕРЕНО] `data/params.json` в корне репозитория остаётся источником измеренных чисел для кода. Этот каталог сохраняет дополнительные наблюдения и исторический словарь, но не меняет новые пользовательские решения. См. [progress.json](../../data/progress.json) и [последнюю стадию](../regular/ka/).
