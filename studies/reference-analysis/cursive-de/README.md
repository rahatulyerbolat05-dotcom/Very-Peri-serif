# Письменная д: реальные кириллические конструкции

[РЕШЕНИЕ · 15.10.2026] Пользователь отклонил печатную площадку д и напомнил
письменный/курсивный принцип строчных. Внешние шрифты здесь изучаются по
скелету и движению штриха; их контуры не переносятся в Very Peri.

[ИЗМЕРЕНО] [Лист сравнения](cursive-de-real-references.svg) содержит восемь
реальных строк из шести семейств: U+0434, собственная латинская g и «доди».
Набор выполнен HarfBuzz с указанным языком и функциями. У всех показанных
файлов UPM 1000, вес 400; у Literata opsz 12. Наклон и оригинальные
интервалы сохранены, отдельные глифы не растягивались и не выпрямлялись.
Это лист источников, а не презентация новых контуров Instrument.

| Шрифт / выбор | Реальная конструкция д | Значение для разработки |
|---|---|---|
| Lora Italic, русский по умолчанию | Одна чаша, верхний возвратный штрих | Верхневыносное направление без нижней петли g |
| Literata Italic, русский по умолчанию | Одна чаша, компактный верхний загиб | Сдержанная организация верхнего движения |
| EB Garamond Italic, русский по умолчанию | Одна чаша и верхний вынос; g двухэтажная | Конструктивное различие д/g видно в одной гарнитуре |
| Playfair Display Italic, русский по умолчанию | Одна чаша и открытый верхний штрих | Другой характер верхнего входа |
| Cormorant Infant Italic, по умолчанию | Одночашевая нижневыносная; контур равен своей g | Наличие в кириллическом шрифте само по себе не решает претензию к чтению как g |
| Cormorant Infant Italic, ss10 | Верхневыносная одночашевая | Две конструкции действительно предусмотрены в одном шрифте |
| Lora Italic, bg / locl BGR | Нижневыносная, равна своей g; рисунок совпадает с SRB | Локализованный выбор, не русская форма по умолчанию |
| Alegreya Italic, sr / locl SRB | Нижнепетлевая, равна своей g | Ещё один реальный языковой вариант, а не общий шаблон для д |

[ИЗМЕРЕНО] В EB Garamond есть именованный нижний контур uni0434.SRB,
отличающийся от g, но загруженный файл не выбирает его через cyrl locl
при HarfBuzz sr. Он не выдаётся за работающую локализацию на листе.
Cormorant Upright 3.302 вообще не имеет U+0434: это отрицательный контроль,
не референс кириллической д. Нельзя выводить доступность формы из имени
семейства или имени глифа без проверки cmap и реального shaping.

[НАБЛЮДЕНИЕ] Для текущей задачи перспективна верхневыносная письменная д:
она меняет класс силуэта после отклонённых двухэтажной g и печатной площадки.
В нашей Regular её нужно строить с полной чашей o, вертикальной осью,
родным контрастом и новым правым верхним ходом. Проверка «бд дб» нужна,
чтобы верхневыносная д не стала зеркальной версией выбранной б.
Конкретная новая д остаётся неутверждённой.
