# Плоская ножка н перед буквами без засечки · Regular 1.009

[РЕШЕНИЕ · 17.10.2026] По просьбе автора, зеркально к выходной ножке к (docs/ka-flag.md):
основная н (n4) сохраняет выходную ножку u на правой стойке рядом с буквой, у которой
есть нижняя левая засечка (`@serif_bl`: п, н, к, и, т, ш…), и в конце слова. Перед
буквами без такой засечки (о, с, е, а, э, з, ч, я, у, х, б, р и их варианты; класс
`@no_serif_bl` собирается сборкой как дополнение к `@serif_bl`) ставится `uni043D.flat`:
нижние 150 единиц правой стойки взяты у ı оригинала (плоская симметричная засечка,
ножка 68, как у левой стойки), края стойки на y=150 совпадают без ступеньки.
Зазор между засечками ножек 56–60 при латинской n 54.

Реализация: `tools/en_flat.py`, источник `data/en/n4.glif` (контрольная сумма в
`data/en-flat/manifest.json`), правило `sub uni043D' @no_serif_bl by uni043D.flat;`
в lookup `calt_feet`. Проверка `tools/check_draft_font.py`: для каждой следующей
буквы алфавита ожидаемое имя н считается по классу. Заглавная Н (латинская H) и ң
не меняются.
