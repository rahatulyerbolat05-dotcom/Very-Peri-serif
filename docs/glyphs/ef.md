# ф (U+0444, ef-cy), строчная

Статус на 15.10.2026: **контур ф убран из репозитория по просьбе автора проекта** («ф отпушь обратно, я попрошу GPT запушить, у тебя она кривится»). Автор проекта вставит свой вектор сам.

- Образцы автора проекта (его чертежи, остаются в репозитории): `docs/img/author_ef_reference.svg` (первый), `docs/img/author_ef_vector.svg` (последний).
- Для вставки без изменений формы есть `tools/embed_author_svg.py` (масштаб 945 / высота viewBox, верх 740, левое поле 23); моя вставка в этой сессии давала контур с точно такой же площадью, как у SVG (141 499), но автор проекта видел искажение; проверку на стороне GPT или в редакторе проводит автор проекта.
- Замеры образца (для проверки): стойка 68 (x 223–291, ось 257), боковая стенка овалов около 61, верх и низ колец 25, овалы 516 / −9, не эллипсы, ширина 514,5, низ стойки −202,3 в последнем векторе.
- Мои отклонённые эскизы: овал о со стойкой, два эллипса, суперэллипсы по замерам (`ef_sign`, `ef2_sign`, `ef3_sign` в `tools/glyphparts.py`, только для истории).
- Азбука и `built_bases` ф не содержат до появления контура от автора проекта.
