# ф (U+0444, ef-cy), строчная

Статус на 15.10.2026: **убрана из репозитория по просьбе автора проекта** («ф отпушь обратно, я попрошу GPT запушить, у тебя она кривится»). Ф ожидается от автора проекта через GPT (контур в `data/ef/`, как у остальных букв: `ef.glif`, `.svg`, затем запись в `data/alphabet.json` и `data/context/serif_bl.json`, `built_bases`).

Проверка вставки (для GPT и для себя): вектор автора проекта при вставке `tools/embed_author_svg.py` сохраняет площадь точно (141 499 единиц, три контура, кривые не упрощаются); если после своей вставки линии пропадают, сверять площадь и число подконтуров с исходным SVG.
