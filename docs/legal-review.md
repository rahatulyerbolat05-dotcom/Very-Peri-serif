# Юридическая проверка Very Peri Serif (20.10.2026)

Это разбор рисков, а не юридическая консультация. Для коммерческого выпуска под своим брендом имя стоит проверить у патентного
поверенного (пункт 3).

## 1. Лицензия: SIL OFL 1.1

Шрифт — изменённая версия Instrument Serif (OFL 1.1, без зарезервированных имён), а буква д в Regular — изменённый контур
Cormorant Garamond (OFL 1.1, без зарезервированных имён). Отсюда пять правил OFL, которые действуют на Very Peri Serif:

| Условие OFL | Что значит для проекта | Состояние |
|---|---|---|
| 1. Шрифт нельзя продавать сам по себе | Файл шрифта нельзя продавать отдельно; можно продавать вместе с программой, услугой, набором | учесть при продаже |
| 2. Каждая копия несёт копирайт и лицензию | В пакете OFL.txt с копирайтом Instrument, проекта и Cormorant; Cormorant-OFL.txt и NOTICE | исправлено |
| 3. Зарезервированные имена | У Instrument и Cormorant их нет; своё имя Very Peri Serif не содержит «Instrument» | выполнено |
| 4. Имена авторов оригинала не для рекламы | Упоминание «основан на Instrument Serif» в описании допустимо; «шрифт от Instrument» нельзя | выполнено |
| 5. Производная только под OFL | Very Peri Serif остаётся под OFL 1.1, другую лицензию поставить нельзя | выполнено |

Свободно разрешено: использовать шрифт в любых коммерческих макетах, логотипах, сайтах, приложениях, печати; результат
(картинка, документ) лицензией не связан.

### Cormorant

Буква д в Regular — не «подсмотренный принцип», а сам контур Cormorant, изменённый: `tools/cormorant_de_proportions.py`
загружает глиф д Cormorant Garamond (ss10) и меняет пропорции, дальше `width-refinement`, `condense-bowls`, `neck-repair`.
Решение записано в CLAUDE.md («автор явно велел взять сам контур Cormorant»). Поэтому копирайт и лицензия Cormorant в Regular
обязательны (условие 2). В курсиве контуров Cormorant нет, его копирайт и описание теперь без Cormorant.

Убрать Cormorant из документов законно можно только одним путём: заменить д в Regular своей (из родных частей Instrument),
тогда файлы Cormorant уходят из пакета.

## 2. Авторство и ИИ (Закон РК «Об искусственном интеллекте», в силе с 18.01.2026)

- Охрана: произведение с участием ИИ охраняется авторским правом только при творческом вкладе человека. Вклад автора здесь
  записан: задание и инструкция, выбор и отклонение вариантов, правки, собственные чертежи (журнал CLAUDE.md, FONTLOG.txt).
  Для OFL это важно меньше, чем для закрытого шрифта: шрифт и так открыт, но авторство даёт право требовать соблюдения OFL.
- Прозрачность (ст. 21): пользователь должен знать, что продукт создан с помощью ИИ. Сделано: строка в описании шрифта
  (name ID 10), FONTLOG.txt, AUTHORS.txt. Точный объём обязанности (машиночитаемая маркировка «синтетического контента»)
  в публикациях описан по-разному, его стоит сверить с текстом закона.
- Изучение других шрифтов только для измерений (пропорции, толщины) не является копированием контуров и в документах
  не перечисляется.

## 3. Имя «Very Peri»

Very Peri — название цвета PANTONE 17-3938, «цвет 2022 года». Регистрации товарного знака «Very Peri» в открытых
источниках не найдено (зарегистрирован знак PANTONE). Есть единичный отчёт продавца, у которого площадка снимала товары с
тегом «very peri». Риск для бесплатного открытого шрифта низкий; для коммерческого бренда перед выпуском проверить:
USPTO (tmsearch.uspto.gov), WIPO Global Brand Database, реестр НИИС Казахстана (класс 9 — шрифты как программы, класс 42).
Запасной вариант — имя без «Very Peri».

## 4. Чек-лист коммерческих рисков (из правил автора)

| Пункт | Для шрифта |
|---|---|
| 1–4 Политика конфиденциальности, данные, ИИ, трекеры | Шрифт данных не собирает. Нужна, только если будет сайт/магазин для раздачи: тогда указать аналитику и ИИ |
| 5 Удаление загрузок пользователей | Не применимо (загрузок нет) |
| 6 Закрытые хранилища | Репозиторий и архивы публичны намеренно (OFL); секретов в них нет |
| 7 Поддельные отзывы | Не применимо; в описаниях не писать чужих отзывов |
| 8–9 Подписка, напоминание | Не применимо: OFL запрещает продавать шрифт сам по себе, подписка на один шрифт невозможна |
| 10 ИИ-бот и селф-харм | Не применимо |

## 5. Что исправлено в пакете

- `OFL.txt`: шапка с копирайтом Instrument, проекта и Cormorant (раньше только Instrument).
- `AUTHORS.txt`: настоящий список авторов (раньше шаблон Instrument без строки о кириллице, вопреки пункту 1 CLAUDE.md).
- `FONTLOG.txt`: что изменено против оригинала, как сделано, участие ИИ, вклад автора.
- Name ID 9/10: автор кириллицы и пометка об ИИ; у курсива свои копирайт и описание без Cormorant.
- Источники: `font/legal/`, параметры `regular_release.cyrillic_author`, `regular_release.ai_note` в `data/params.json`.
