## SIL Open Font License 1.1

Very Peri Serif распространяется под SIL OFL 1.1. Тело лицензии в `OFL.txt`
побайтно сравнивается с обеими локальными исходными копиями; меняется только
шапка уведомлений об авторском праве. В шапках этих копий нет объявления
Reserved Font Name. Это не результат поиска сторонних товарных знаков:
такой поиск не выполнялся, и отсутствие чужих прав на название не гарантируется.

Полные условия находятся в [OFL.txt](../OFL.txt), справка —
<https://openfontlicense.org>. Лицензия разрешает использование, изменение
и распространение на её условиях; шрифт нельзя продавать сам по себе.
При распространении сохраняются уведомления и лицензия, производный шрифт
остаётся под OFL. Лицензия шрифта не распространяется на созданные им документы.

Приватный репозиторий совместим с OFL: публичный GitHub не является её условием.
Смена видимости не отменяет лицензию уже распространённых копий и не отзывает
ранее предоставленные получателям права.

## Встроенная информация

Во всех TTF, OTF и WOFF2 проверяются:

- name ID 0: Instrument + Yerbolat Rakhatuly (DEW); также Cormorant для Regular;
- name ID 8: Yerbolat Rakhatuly (DEW), издатель этого расширения;
- name ID 9: оригинальный дизайнер и автор кириллического расширения;
- name ID 10: происхождение и добровольное раскрытие участия ИИ;
- name ID 11/12: ссылки проекта и профиля автора;
- name ID 13/14: SIL OFL 1.1 и адрес лицензии;
- OS/2 fsType = 0: нет технических ограничений встраивания;
- версия 1.113, корректная связь Regular/Italic, отдельные PostScript-имена.

ИИ указан как инструмент разработки, а не как правообладатель. `ai-disclosure.json`
содержит сведения о происхождении. Здесь не утверждается, что эта добровольная
пометка сама по себе выполняет все требования законодательства какой-либо страны.
Непроверенные утверждения прежнего документа о законах и товарных знаках удалены.
