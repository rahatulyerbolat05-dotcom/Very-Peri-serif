# Каплевидные хвостики и прежняя альтернатива

[РЕШЕНИЕ · 16.10.2026] Основной хвост у **ц щ қ ң Ц Щ Қ Ң**, включая
запасную и контекстную формы қ, теперь построен по точному SVG пользователя.
Предыдущая перерисовка по скриншоту заменена. Исходный файл сохранён
без изменений: `data/tail-vector-2026-10-16/author-example.svg`.

![Сверху прежний вариант, снизу точная капля](img/drop_tail_variants.svg)

[ИЗМЕРЕНО] Из чёрного контура SVG извлечены восемь кубических сегментов
между точками (541.475,534.523) и (587.585,513.419). Семь сегментов
перенесены со всеми исходными опорными и управляющими точками: только
единый масштаб, перенос и смена направления оси Y. Первая кривая входа
согласована с прежним корпусом: её начальная точка и первая управляющая
точка следуют существующему входу; вторая управляющая и конец — из SVG.
Для щ масштаб практически1, перенос по X составляет15 единиц.

[ИЗМЕРЕНО] В `data/drop-tail-variants/manifest.json` для каждого из10
вариантов записаны SHA256 исходного SVG, аффинное преобразование,
число точных сегментов и разность корпуса выше базовой линии.
XOR-разность выше базовой линии менее0,02 единицы²; ширины сохранены.
Проверены замкнутость и отсутствие самопересечений семплированных колец.
Белые и красный вспомогательные контуры SVG не импортировались.

[РЕШЕНИЕ] Прежние хвосты сохранены без перезаписи исходных GLIF в
`data/alphabet.json` → `user[буква].tail_alternatives` и доступны через
**ss09** в устанавливаемом шрифте. Для қ сохранены primary, alternate
и context; контекстная подстановка работает совместно с ss09.

## Воспроизведение

```sh
XDG_CACHE_HOME=/workspace/.cache MPLCONFIGDIR=/workspace/.cache/matplotlib \
  /workspace/very-peri-venv/bin/python -I tools/drop_tail_variants.py
/workspace/very-peri-venv/bin/python -I tools/check_context_classes.py
XDG_CACHE_HOME=/workspace/.cache MPLCONFIGDIR=/workspace/.cache/matplotlib \
  /workspace/very-peri-venv/bin/python -I tools/alphabet_sheet.py
```

Генератор всегда читает авторский SVG и начинает с сохранённых
`tail_alternatives`. Повторный запуск воспроизводит те же координаты.
Сборка устанавливаемого шрифта описана в `font/README.md`.
